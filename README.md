## TeamCity
## Test automation framework for **API and UI testing**
**Tech stack:**
- Java + Maven
- REST Assured (API tests)
- Selenide + Selenoid (UI tests)
- Docker (TeamCity Server, Agent, Selenoid)
- Allure Reports
- GitHub Actions CI

## Test Reports (Allure)
This project uses **Allure Report** to visualize test execution results and history.
The reports are automatically generated and published via **GitHub Actions** and **GitHub Pages**.
